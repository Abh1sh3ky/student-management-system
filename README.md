# Student Management System

A Student Management System built using React.js.

## Tech Stack

* React.js
* JavaScript
* React Router
* Axios
* JSON Server
* CSS
* Vite

## Features

* Add Student
* Edit Student
* Delete Student
* View Student Details
* Search Students
* Filter Students
* Student Status Management

## Run Locally

Install dependencies:

bash
npm install


Start React app:

bash
npm run dev


Start JSON Server:

bash
npx json-server db.json --port 3000
